Hướng Dẫn Đưa Lên GitHub Pages (Miễn Phí 100%)

Trang web được thiết kế dạng Pure Vanilla Web (HTML5/CSS3/JS) độc lập hoàn toàn, không cần build phức tạp, có thể chạy trực tiếp trên bất kỳ trình duyệt nào và kích hoạt GitHub Pages chỉ trong 2 phút!

1

Đẩy mã nguồn thư mục `Quiz_Devops` lên GitHub

Mở terminal tại thư mục này và gõ các lệnh Git:

git add .
git commit -m "feat: Add interactive DevOps 68 questions quiz app"
git push origin main
2

Bật GitHub Pages trong mục Settings

Truy cập vào Repository của bạn trên GitHub:

  1. Vào tab Settings ⚙️
  2. Chọn mục Pages ở thanh menu bên trái
  3. Tại mục Build and deployment > Source, chọn: Deploy from a branch
  4. Tại Branch, chọn nhánh main và chọn thư mục / (root) hoặc /docs
  5. Bấm Save
3

Nhận link chia sẻ cho cả lớp cùng ôn tập!

Sau 1-2 phút, GitHub sẽ cấp link dạng:

https://<username>.github.io/<repo-name>/Quiz_Devops/
