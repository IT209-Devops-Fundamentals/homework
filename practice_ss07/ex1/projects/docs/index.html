DevOps Knowledge Base

Tài liệu tra cứu nhanh các câu lệnh và cấu hình quản trị hệ thống Linux & Web Server.

Mẹo vàng: Trước khi reload Nginx trong môi trường Production, luôn chạy lệnh sudo nginx -t để đảm bảo không bị lỗi cú pháp làm sập server!

1. Lệnh Nạp Cấu Hình Nginx

# Kiểm tra lỗi cú pháp cấu hình
sudo nginx -t

# Nạp lại cấu hình không gián đoạn kết nối
sudo systemctl reload nginx

# Khởi động lại dịch vụ khi cần
sudo systemctl restart nginx

2. Chuẩn Phân Quyền Thư Mục Web (/var/www)

# Gán sở hữu cho devops và nhóm Nginx
sudo chown -R devops:www-data /var/www/my-site

# Thư mục: 755 (đọc + duyệt thư mục)
sudo find /var/www/my-site -type d -exec chmod 755 {} +

# Tệp tin: 644 (chỉ đọc)
sudo find /var/www/my-site -type f -exec chmod 644 {} +

3. Mở Cổng Tường Lửa UFW

# Mở cổng HTTP & các cổng phụ
sudo ufw allow 80/tcp
sudo ufw allow 8081/tcp
sudo ufw allow 8082/tcp
sudo ufw status verbose
